# txscribe

Transcripts you can check against the audio.

[txscribe](https://txscribe.ai) turns recordings into transcripts where every word is timed: click a line to hear it, fix it without losing the timings, and export TXT, SRT, VTT or DOCX. Speakers are labelled wherever the language supports it, in 82 languages.

Try it without an account at [txscribe.ai/try](https://txscribe.ai/try).
